# Discord GIF Presence

Shows a GIF or image and a line of random symbols as your Discord status. While you play Valorant, it shows your match, for example "Playing · Swiftplay".

## Install on Windows

1. Download `DiscordGifPresence.exe` from the [latest release](https://github.com/MobyScript/discord-gif-presence/releases/latest).
2. Move it to a folder where it can stay, for example `Documents`.
3. Double-click it.
4. If Windows shows "Windows protected your PC", click "More info" and then "Run anyway".

The Discord desktop app must be open. The app starts each time you log in.

## Use it

Right-click the icon in the system tray, at the bottom-right of the taskbar.

- Image from link...: Paste a link to a GIF or image. The link must start with `https://`.
- Image from file...: Pick a GIF or image on your computer, up to 10 MB. The app uploads it to catbox.moe. Anyone with the link can see it.
- Open configuration file: Change the text and the symbols in Notepad.
- Profiles: Save your setup with a name, and switch between saved setups.
- Start at login, Pause, Quit.

## Remove it

Click "Start at login" to remove the check mark, then click "Quit". Delete the `.exe` and the folder `%APPDATA%\discord-gif-presence`.
